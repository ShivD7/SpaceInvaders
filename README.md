# Space Invaders

A browser game built with JavaScript and HTML Canvas.

* Moves the ship with A and D.
* Fires projectiles with Space.
* Spawns moving enemy formations at random intervals.
* Lets enemies fire back.
* Awards 100 points per enemy destroyed.
* Shows the current score.
* Draws a scrolling starfield and particle explosions.
* Ends the game when an enemy projectile hits the player.
